# Utah Maternity & Birth Resource Guide 🌸

A complete, high-performance web resource for Utah expecting mothers, curated by **Andi Photo + Film**.

## ✨ Included Features & Pages

1. **Homepage (`index.html`)**: Editorial entrance highlighting the 4 core pillars with trust badges and statistics.
2. **Birth Place Matcher Quiz (`quiz.html`)**: Apple-inspired multi-step interactive quiz that matches mothers with 28 Utah hospitals, 6 birth centers, or home birth midwives. Includes lead capture sending directly to Google Apps Script / Sheet.
3. **Natural & Non-Toxic Birth Packing Checklist (`checklist.html`)**: Interactive checklist featuring 28 clean items, category pills, progress tracking in localStorage, printable view, and **1-click Amazon Cart sync** (`andiphoto-20`).
4. **Statewide Provider Directory (`directory.html`)**: 50 verified Utah hospitals, birth centers, midwives, and photographers with real-time county and keyword search, plus dynamic sync with active Stripe subscribers.
5. **Partner Onboarding & Advertising (`advertise.html`)**: Tiered pricing table (Basic $0, Featured Pro $39/mo, Quiz Spotlight $89/mo) and intake application form connected to automated badging webhooks.

## 🚀 Deployment

- **Hosting**: Netlify
- **Static Assets**: Pure HTML5, CSS3, Vanilla JS (zero build dependencies, lightning fast).
- **Domain**: Ready for custom domain (e.g. `utahmaternityguide.com` or subdomain `guide.andiphotoandfilm.com`).
